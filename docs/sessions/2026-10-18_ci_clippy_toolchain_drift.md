## المشكلة

لم يسجّل `ci.yml` أي نجاح قبل `fc00287`. التشغيلات الحديثة توقفت عند:

```text
cargo clippy --all-targets --all-features -- -D warnings
```

نجح Clippy على 1.97.1، وفشل على 1.98.0 بتحذيرين `clippy::needless_late_init`
(`src/constraint_engine.rs:72,96`)، وعلى 1.99.0 بهما وبتحذير `clippy::double_must_use`
عند `#[async_trait]` (`src/llm/mod.rs:101`). السبب: CI على Rust `stable` المتحرك.

## الإصلاح الأول — `2f288a8`

تعريف `has_jest_config` و`has_package_json` و`jest_in_pkg_json` عند التصريح. الشروط
وترتيبها والاستدعاءات والقيم لم تتغير. دليل تكافؤ من **مثال مستقل** (لا اختبار الدالة
الإنتاجية) على 32 حالة: `CASES=32 DIFFS=0`. Clippy نجح على 1.97.1 و1.98.0، واختبارات
1.97.1 و1.99.0 نجحت بالأعداد نفسها، وبوابة core عبر الخطاف 84/84.

## الإصلاح الثاني — `fc00287`

```rust
// async_trait expands to #[must_use] fns returning Pin<Box<Future>> (already must_use);
// clippy >= 1.99 reports double_must_use. Localized allow - style of 08bc71f.
#[allow(clippy::double_must_use)]
#[async_trait]
pub trait LLMProvider: Send + Sync {
```

لا `must_use` صريح في المصدر؛ التحذير من توسعة الماكرو. الإباحة على trait واحد.
fmt وClippy (1.97.1/1.98.0/1.99.0) والاختبارات الكاملة نجحت، وبوابة core 84/84،
وأعاد المراجع المستقل القياس بنجاح على Clippy 1.99.1.

## حادثة `CARGO_TARGET_DIR`

ضُبط المتغير لتسريع البناء فظهر فشل قابل للتكرار في `rust_nested_mutation`:

```text
بلا المتغير                        -> 3 passed
مع المتغير                         -> 2 passed, 1 failed
مع المتغير + test-threads=1        -> 3 passed
شجرة معزولة على 1.99 بلا المتغير  -> 3 passed، والمجموعة الكاملة نجحت
```

**الأثر مقاس** (N46). **الآلية الداخلية** (توارث المتغير / تصادم `add_lib` بين اختبارين
متوازيين) **استنتاج غير مثبت** بطباعة بيئة العملية الابنة (N47). N45 **مسحوبة**.
تحسين العزل قضية مستقلة مفتوحة (N49).
